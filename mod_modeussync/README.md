# Задания из Modeus (`mod_modeussync`)

Activity-плагин предоставляет преподавателю ручной этап создания оцениваемых элементов по заданиям, уже полученным `tool_modeussync` от SyncService.

## Установка и зависимость

Плагин требует установленный `tool_modeussync` совместимой версии. Он использует очередь, настройки подключения (`syncservice_base_url`, `internal_api_key`) и публичный клиент `tool_modeussync\service\SyncService`; контракты SyncService не изменяются.

`tool_modeussync` и `mod_modeussync` необходимо развёртывать из одного релиза. После замены файлов запустите обновление Moodle и очистите кеши; при использовании PHP OPcache также перезапустите PHP-процессы. Это исключает загрузку нового интерфейса `mod_modeussync` со старой моделью очереди `tool_modeussync`.

На курсе может существовать ровно один экземпляр `mod_modeussync`. Он создаётся системой только при наличии заданий в очереди. Добавление и удаление через стандартный интерфейс Moodle запрещены; отсутствующий экземпляр восстанавливает фоновая задача.

## Работа преподавателя

1. Откройте «Задания из Modeus» на странице курса.
2. Для каждой строки выберите тип: «Задание» (`assign`, выбран по умолчанию), «Тест» (`quiz`) или «Семинар» (`workshop`).
3. При необходимости введите переопределение названия. Пустое или состоящее только из пробелов поле оставляет название из Modeus.
4. Нажмите «Создать».

Название из Modeus, `course_modules.idnumber` и максимальная оценка каждого созданного элемента берутся из `courseData`. Непустое переопределение используется только для имени нового элемента; исходное имя в очереди сохраняется. Переопределение сохраняется для строк с ошибкой и используется при повторном создании, но уже существующие элементы автоматически не переименовываются. Moodle хранит максимум `assign` как целое число, поэтому дробное значение для выбранного `assign` отклоняется без округления; его можно создать как `quiz` или `workshop`, которые поддерживают дробной максимум. `quiz` создаётся пустым, с одной попыткой и методом итоговой оценки «Лучшая оценка»; вопросы преподаватель добавляет самостоятельно.

`workshop` — стандартный элемент Moodle «Семинар». Он создаётся в фазе настройки без работ и формы оценивания. Максимальная оценка из Modeus используется как оценка за представленную работу, а оценка за оценивание работ устанавливается в `0`. После создания преподавателю необходимо открыть семинар, настроить инструкции и форму оценивания, а затем переключать его фазы в соответствии с учебным процессом.

При частичной ошибке уже созданные элементы сохраняются, а повторная попытка обрабатывает только отсутствующие. `POST /sync` вызывается только после создания или обнаружения всех элементов. Если ошибка произошла только при `/sync`, повторная попытка не создаёт элементы заново и повторяет только отправку неизменной связки `id_modeus`/`id_lms`.

Созданные `assign`, `quiz` и `workshop` затем передаются через штатную задачу `tool_modeussync\task\push_courses`; технический `modeussync` не экспортируется.

## Права

- `mod/modeussync:view` — просмотр очереди;
- `mod/modeussync:manage` — выбор типов, создание элементов и повторная отправка;
- `mod/modeussync:addinstance` — служебная capability без стандартных назначений ролям; сама по себе не разрешает ручное добавление.
