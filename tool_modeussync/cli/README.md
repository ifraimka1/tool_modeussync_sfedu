# Удаление курсов по периоду

Скрипт `delete_courses_by_period.php` удаляет курсы через штатную Moodle API-функцию `delete_course()`. Это позволяет Moodle корректно удалить связанные элементы курса, контексты, оценки, файлы и данные плагинов.

## Какие курсы выбираются

Курс должен одновременно соответствовать двум условиям:

- находиться в категории с ID `113`;
- содержать в полном названии один из периодов:
  - `(01.09.2025-07.02.2026)`;
  - `(08.02.2026-30.07.2026)`.

Период может находиться в любой части полного названия курса.

## Использование

Команды следует выполнять из корневого каталога Moodle.

Сначала запустите безопасный режим предпросмотра:

```bash
php admin/tool/modeussync/cli/delete_courses_by_period.php
```

Скрипт выведет найденные курсы, но ничего не удалит. Проверьте количество курсов, их ID, короткие и полные названия.

Для удаления показанных курсов выполните:

```bash
php admin/tool/modeussync/cli/delete_courses_by_period.php --execute
```

Справка по параметрам:

```bash
php admin/tool/modeussync/cli/delete_courses_by_period.php --help
```

## Результаты выполнения

- `MATCH` — курс найден в режиме предпросмотра;
- `DELETED` — курс успешно удалён;
- `SKIPPED` — перед удалением курс перестал соответствовать условиям или уже отсутствует;
- `FAILED` — Moodle не смог удалить курс; после статуса выводится описание ошибки.

В конце выводится количество удалённых, пропущенных и завершившихся ошибкой курсов. При наличии хотя бы одной ошибки скрипт возвращает ненулевой код завершения.

## Меры безопасности

- Без параметра `--execute` удаление невозможно.
- Непосредственно перед удалением каждого курса повторно проверяются его категория и полное название.
- Ошибка одного курса не останавливает обработку остальных.
- Скрипт не выполняет прямые SQL-запросы `DELETE`.
- Скрипт не предоставляет откат удаления. Перед запуском с `--execute` убедитесь, что доступна актуальная резервная копия Moodle.

Категория и периоды заданы непосредственно в скрипте. Если критерии отбора нужно изменить, сначала отредактируйте их и снова выполните запуск без `--execute`.
